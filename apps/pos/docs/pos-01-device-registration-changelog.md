## What's New

### New Routes

| Route | Path | Description |
|---|---|---|
| Device Registration | `/new-device` | 6-digit pairing code entry screen |
| Staff Selection | `/staff-selection` | Placeholder for per-transaction staff picker |

Both routes are grouped under `(auth)/` in the file system but exposed as top-level URLs.

### Root Path Redirect (`/`)

The root path now acts as a gateway:
- **If `rms_device_id` and `rms_device_session` exist in `localStorage`** → redirects to `/staff-selection`
- **If missing or expired** → redirects to `/new-device`

No user ever lands on an empty root page.

## Device Registration Screen (`/new-device`)

### Visual Design
- Centered card layout on mint-green (`--background`) background
- Black 1px solid border (`border-foreground`) with `rounded-sm` radius
- 6 individual PIN input boxes: `h-14 w-12` with `text-2xl font-mono`
- Grouped visually: `[1][2][3] — [4][5][6]`
- "Need help? Contact your outlet manager." positioned directly below the card

### Interaction
- **Auto-focus:** Cursor moves forward on each digit entry
- **Backspace:** Clears current box, moves back to previous
- **Arrow keys:** Left/right navigation between boxes
- **Paste:** Fills all 6 boxes from clipboard, filtered to digits only
- **Auto-submit:** Completing the 6th digit triggers validation instantly — no Confirm button
- **Enter key:** Also triggers submit from any focused box

### Form Validation
- **React Hook Form** with **Zod** schema:
  - `pin: string.length(6).regex(/^\d{6}$/)`
- Error messages display inline below the input group
- On validation error, boxes auto-clear after **4 seconds** and focus returns to the first box

### Mock API
- Simulated 800ms network delay
- **Valid code:** `123456`
- On success:
  - Stores `rms_device_id`, `rms_device_session`, `rms_outlet_name`, `rms_outlet_id` in `localStorage`
  - Navigates instantly to `/staff-selection`
- On failure: inline error, inputs disabled during validation, "Validating…" text shown

### Dependencies Added
- `react-hook-form@7.76.1`
- `@hookform/resolvers@5.4.0`
- `zod@3.25.76` (already available in workspace, added to `apps/pos`)
