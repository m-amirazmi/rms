# Changelog — POS v0.0.3

## Feature: Application Shell & Layout (pos-03)

### Added

- **WizardShell** (`src/components/wizard-shell.tsx`) — Responsive flex-column layout wrapping all wizard routes. Desktop (`lg+`) shows two-column layout with persistent `SummaryPanel`. Tablet (`md`) shows collapsible `SummaryBar`. Mobile (`<md`) shows sticky `SummaryPeek` above bottom nav.
- **TopBar** (`src/components/top-bar.tsx`) — App header using `grid-cols-12` for true-centre breadcrumb alignment. Left: logo. Centre: breadcrumb slot (hidden on mobile). Right: outlet badge, language toggle, avatar.
- **BottomNav** (`src/components/bottom-nav.tsx`) — Sticky bottom bar with Previous/Continue buttons. Derives step from current URL via `useLocation()` + `WIZARD_STEP_ROUTES`. On final step, Continue becomes "Create Job".
- **WizardBreadcrumb** (`src/components/wizard-breadcrumb.tsx`) — Read-only step indicator with check icons for completed, primary bold for current, muted for future. Derives active step from route URL.
- **LanguageToggle** (`src/components/language-toggle.tsx`) — Two-segment `[EN | MY]` control. Active segment uses primary colour. Persisted to `localStorage` via `useLanguageStore`.
- **AvatarPopover** (`src/components/avatar-popover.tsx`) — Staff avatar dropdown with "Switch staff member" (→ `/select-staff`) and "Cancel intake" (opens confirmation dialog). Uses Radix `Popover` + `Dialog` primitives.
- **SummaryPanel** — Persistent right sidebar (`lg+`) showing mock repair summary.
- **SummaryBar** — Collapsible bar (`md`) above wizard content.
- **SummaryPeek** — Sticky peek bar (`<md`) above bottom nav.
- **Popover & Dialog** primitives added to `@workspace/ui` — Radix-based, following existing `data-slot` + `cn()` conventions.
- **All 6 wizard routes** created under `routes/(wizard)/_layout.*`:
  - `/select-category` — Step 1
  - `/select-brand-model` — Step 2
  - `/select-issues` — Step 3
  - `/select-parts` — Step 4
  - `/customer-tech` — Step 5
  - `/repair-summary` — Step 6
- **Zustand stores** co-located in feature folders:
  - `features/language/language-store.ts` — `EN` | `MY`, persisted to `rms_language`
  - `features/wizard/wizard-store.ts` — step index, form data accumulation, `WIZARD_STEP_ROUTES`, persisted to `rms_wizard`
- **Pathless layout** (`routes/(wizard)/_layout.tsx`) with `beforeLoad` guard — redirects to `/select-staff` if no `rms_staff_id` in `localStorage`.

### Changed

- **Refactored stores into feature folders** — Removed unused top-level `src/store/`, `src/contexts/`, `src/i18n/`, `src/types/` directories. Stores now live at `features/language/` and `features/wizard/`.
- **TopBar grid layout** — Switched from flex `justify-between` to `grid-cols-12` (3-6-3) so the breadcrumb is truly centred regardless of left/right content width.
- **Summary components** — Eliminated `getSummary()` store anti-pattern. Now subscribe only to `currentStepIndex` (primitive) and render static mock data imported at module level. Prevents cascading re-renders and infinite loops.
- **Documentation restructured** into `architecture/`, `components/`, `specifications/`, `changelog/` folders.

### Fixed

- Maximum update depth exceeded error in `SummaryBar` — caused by subscribing to a store method that returned a new object on every call. Fixed by only selecting primitive values from Zustand stores.

### Technical Details

- Added `zustand@5.0.13` dependency with `persist` middleware
- Wizard routes use TanStack Router dot notation (`_layout.select-category.tsx`) for automatic nesting under the pathless layout
- Route tree auto-generates `routeTree.gen.ts` with proper parent-child relationships
- All shell components use Phosphor Icons exclusively (no Lucide)
- All styling uses CSS variable tokens (`bg-background`, `text-primary`, etc.) — no hardcoded colours
