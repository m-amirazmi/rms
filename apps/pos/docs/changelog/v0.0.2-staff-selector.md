# Changelog — POS v0.0.2

## Feature: Staff Selector & Identity (pos-02)

### Added
- **Staff selection screen** (`/select-staff`) — responsive card grid with 6 mock staff members, avatars, position badges, last-active times, daily ticket counts
- **PIN authentication overlay** — 4-digit PIN input with auto-focus, auto-submit, keyboard nav, paste support, shake animation on wrong PIN, 5-attempt lockout with 5-minute countdown timer. Mock PINs per staff member
- **AuthTopbar** — `Storefront` icon, "RepairFlow POS" title, "KL Branch" badge, designed for reuse in wizard steps
- **Select category placeholder** (`/select-category`) — empty wizard step 1 page ready for category grid

### Changed
- **Refactored to feature-based architecture** — extracted `select-staff`, `new-device`, `select-category` into `src/features/<feature>/` with each owning types, constants, schemas, API, utils, components, and README. Route files are now thin TanStack Router wrappers
- **Updated `ui-style-guide.md`** — feature module organization and route file conventions
- **Added `frontend-architecture.md`** — feature-based folder structure, module anatomy, dependency direction guidelines

### Fixed
- TypeScript `verbatimModuleSyntax` type import errors
- `baseUrl` deprecation warning in `tsconfig.json`

### Technical Details
- Route renamed: `/staff-selection` → `/select-staff`
- Added `animate-shake` keyframe to `globals.css`
- All features use `import type` for type-only imports
