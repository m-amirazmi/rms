# Changelog — POS v0.0.4

## Feature: Step 1 — Device Category (pos-05)

### Added

- **Category selection grid** (`features/select-category/components/category-card.tsx`) — 6 tappable radio-style cards (Smartphone, Laptop, Tablet, Wearable, Console, Other) in a responsive 2-column layout. Each card features:
  - Radio indicator (selected / unselected)
  - Large icon with soft-colored background (`size-16`, `rounded-xl`)
  - Label, description, and metadata row with Phosphor icons (model count `Cube`, avg repair time `Clock`, daily intakes `TrendUp`)
  - Popular brand pills (e.g. `Apple` `Samsung` `Xiaomi` `Oppo`)
  - Price-from badge (e.g. `From RM 80`)
  - Optional tag/badge (`Most Popular`, `Trending`, `Last used`)
- **Urgency selector** — Three chip buttons below the grid: `Standard` (Clock icon), `Express` (Lightning icon), `Warranty` (ShieldCheck icon). Defaults to `Standard`, persists to wizard store, reflected in summary panel.
- **Inspection fee Alert** — Uses shadcn `Alert` component with amber `Warning` icon. Shows "Standard Inspection Fee — RM 30.00" in bold with waiver subtext. Dismissible via × button.
- **Cancel Intake** — Ghost `Button` (shadcn) placed top-right of the step content, aligned with the title row. Opens a confirmation dialog; on discard calls `resetWizard()` and redirects to `/select-staff`.
- **Zod + React Hook Form validation** — `CategorySchema` validates `category` (required enum) and `urgency` (optional enum). `mode: "onChange"` drives BottomNav Continue button state.
- **BottomNav integration** — Continue button is disabled on Step 1 (`/select-category`) until a valid category is selected, validated via wizard store.
- **Summary panel updates** — `SummaryContent` now dynamically shows:
  - Selected **category icon + name** (no badge)
  - **Urgency** with colored dot indicator (gray / amber / teal)
  - No badge styling — plain text for a cleaner look
- **New shadcn component** — `Alert`, `AlertTitle`, `AlertDescription` added to `@workspace/ui` following existing `data-slot` + `cn()` conventions.

### Changed

- **Category card border** — Thinned from `border-2` to `border` (1px) to match the select-staff card style.
- **Category card padding** — Reduced from `p-6` to `p-4` for tighter, more compact cards.
- **Category card alignment** — Switched from `items-center` to `items-start` so content anchors to the top, eliminating vertical whitespace.
- **Page layout** — Removed `justify-center` and `max-w-lg` constraints. Grid uses `content-start` and `items-stretch` to fill the viewport naturally.
- **Text sizing** — Increased across the board for POS readability: title `text-lg`, body `text-base`, card labels `text-base`, descriptions `text-sm`, metadata `text-sm`.
- **Summary panel** — Removed Badge usage for category and urgency; now uses plain text + icon/category dot for a flatter, less cluttered look.

### Technical Details

- Feature follows the monorepo feature-module convention: `features/select-category/` with `types.ts`, `constants.ts`, `schemas.ts`, `components/category-card.tsx`, `components/select-category-page.tsx`, and barrel `index.ts`.
- No cross-feature imports — `features/select-category` only imports from `@/features/wizard` (store) and `@workspace/ui` (components).
- `updateFormData("category", { category, urgency })` merges Step 1 data into the wizard store; persisted to `localStorage` via Zustand `persist` middleware.
- Wizard store (`WizardFormData`) expanded with `urgency?: string` field.
- All icons are Phosphor (`@phosphor-icons/react`); no Lucide.
- All colors use CSS variable tokens (`border-primary`, `bg-primary/10`, `text-accent`, etc.); no hardcoded hex values.
