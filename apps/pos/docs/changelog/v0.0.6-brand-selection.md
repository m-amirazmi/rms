# Changelog — POS v0.0.6

## Feature: Category-Scoped Brand Selection (pos-06)

### Added

- Searchable brand picker filtered by the selected device category.
- Local SVG wordmarks for the brands shown in the prototype catalog, with a text fallback if an image fails to load.
- Category-scoped demo metrics for catalog models, completed repairs, compatible parts/SKUs, parts used, and average turnaround.

### Changed

- Persist brand selection in wizard form data and clear stale brand/model values when the device category or selected brand changes.
- Restore a previously selected device category when returning to Step 1.

### Fixed

- Redirect to category selection if Step 2 is opened before a category is selected.
- Prevent continuing to diagnostics until the model-selection portion of Step 2 is implemented.

### Technical Details

- All displayed brand metrics are prototype data; no API or live repair analytics are connected.
- Brand and model selection remain within the existing `/select-brand-model` route; model selection is deferred to a later increment.
