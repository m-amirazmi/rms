# Changelog — POS v0.0.5

## Feature: PWA Support (pos-06)

### Added

- **PWA manifest** (`vite-plugin-pwa`) — Auto-generated `manifest.webmanifest` with:
  - App name: "Baiki POS", display: `standalone`, orientation: `natural`
  - Theme color: `#4f46e5` (indigo primary), background: `#f7fdf7` (mint)
  - Icons: 192×192 and 512×512 PNGs with `any maskable` purpose
- **Service worker** — Auto-generated via Workbox, precaches all build assets (JS, CSS, HTML, fonts, icons) for offline shell loading.
- **Service worker registration** (`src/main.tsx`) — `registerSW({ immediate: true })` from `virtual:pwa-register` enables auto-update on new builds.
- **PWA meta tags** (`index.html`) — Added `theme-color`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style`, `apple-mobile-web-app-title`, and `apple-touch-icon` link for iOS Safari.
- **Viewport lock** (`index.html`) — `maximum-scale=1.0, user-scalable=no` for tablet POS ergonomics.
- **Custom icon set** (`public/`) — Three icons generated to match the `Brand` component visual (indigo rounded square + white storefront icon):
  - `icon-192x192.png`
  - `icon-512x512.png`
  - `apple-touch-icon.png` (180×180 with iOS-safe padding)
- **Type declarations** (`src/vite-env.d.ts`) — Reference types for `vite-plugin-pwa/client` to support `virtual:pwa-register` imports.

### Changed

- **Page title** — Updated from `vite-monorepo` to `Baiki POS`.
- **Vite config** — Added `VitePWA()` plugin with manifest config, Workbox glob patterns, and dev-mode PWA support.

### Technical Details

- Uses `vite-plugin-pwa@1.3.0` with `generateSW` mode (zero-config Workbox).
- Added `workbox-window@7.4.1` as dev dependency for runtime SW registration.
- Icons were generated programmatically via `jimp` to match the existing `Brand` component (primary indigo `#4f46e5` background + white storefront glyph).
- No API runtime caching — offline support is limited to app shell assets only.
- All PWA assets live in `apps/pos/public/` and are copied to `dist/` at build time.
