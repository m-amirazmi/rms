# Changelog — POS v0.0.1

## Feature: Device Registration & Initial Setup (pos-01)

### Added
- **Turborepo monorepo** (Bun + Vite + React 19 + TanStack Router)
- **Theme "Sharper Pop"** — mint-green background, indigo primary, teal secondary, amber accents. Full light/dark mode via CSS variables
- **`packages/ui`** — shared shadcn/ui library with Button, Badge, Card, Input, Avatar, Label, Separator, Switch, Breadcrumb components
- **Device registration screen** (`/new-device`) — 6-digit PIN pairing with auto-focus, keyboard nav, paste support, auto-submit, React Hook Form + Zod validation. Mock API validates against code `123456` with 800ms simulated delay
- **Root gateway route** (`/`) — redirects to `/new-device` or `/staff-selection` based on `localStorage` session
- **Staff selection placeholder** (`/staff-selection`)
- **Header component** with breadcrumb wizard steps and KL Branch badge
- **ThemeProvider** for dark mode toggle
- **Design tokens** in `globals.css` — `@theme inline` mapping, chart palette, sidebar tokens, shadow tokens, border radius scale

### Dependencies Added
- `react-hook-form@7.76.1`
- `@hookform/resolvers@5.4.0`
- `zod@3.25.76`
