# Changelog — POS v0.0.1

## Feature: Device Registration & Initial Setup (pos-01)

### Added
- **Turborepo monorepo setup** (Bun + Vite + React 19 + TanStack Router)
- **Device registration screen** (`/new-device`) with 6-digit pairing code input
  - Split-3 grouping (`XXX—XXX`) with auto-focus, keyboard navigation, paste support
  - React Hook Form + Zod validation
  - Mock API validates against code "123456"
  - Auto-submit on last digit, auto-clear error after 4 seconds
- **Root layout** with `TanStackRouterDevtools`
- **Gateway route** (`/`) — redirects to `/new-device` or `/staff-selection` based on `localStorage`
- **Staff selection placeholder** (`/staff-selection`)
- **Theme "Sharper Pop"** by Muhamad Amir
  - Mint-green background, indigo primary, teal secondary, amber accents
  - Full light and dark mode support via CSS variables
- **`packages/ui`** — Shared shadcn/ui component library
  - Button, Badge, Card, Input, Avatar, Label, Separator, Switch, Breadcrumb components
  - CVA-based variants, `cn()` utility with `clsx` + `tailwind-merge`
- **Design tokens** defined in `globals.css`
  - Full `@theme inline` mapping
  - Chart palette, sidebar tokens, shadow tokens, border radius scale
- **Header component** with breadcrumb wizard steps and KL Branch badge
- **ThemeProvider** for dark mode toggle
